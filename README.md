# fiztech-online
Физтех Онлайн — школа нового поколения для учеников 1–11 классов, объединяющая сильное академическое образование, искусственный интеллект, персональное наставничество и развитие предпринимательского мышления через реальные проекты.

Четыре возрастные программы: **1–4 — «Первооткрыватель»**, **5–7 — «Исследователь»**, **8–9 — «Создатель»**, **10–11 — «Автор будущего»**.

## Демо-кабинет Физтех OS

`demo.html` — отдельный адаптивный кабинет в фирменных цветах школы. Разделы: мой день, курсы с фильтрами, мессенджер, дневник с расписанием и заданиями, проекты, сообщество, уведомления, сценарный Физтех AI и профиль. Атом с логотипом справа внизу открывает справочного помощника с готовыми ответами и переходами к разделам.

Кабинет работает на локальных ресурсах `demo.js`, `demo.css`, `os-assistant.js` и `os-assistant.css`. Все учебные данные вымышлены. Переписка, прикрепление файлов и прохождение уроков имитируются в текущей вкладке; сервер, настоящая отправка сообщений и сохранение данных не подключены. Состояние сбрасывается при перезагрузке.

## Безопасность

Публичный адрес — https://phystechonline.ru/ . Ограничения браузера и автоматические проверки описаны в [SECURITY.md](SECURITY.md). Для устранения надписи «Не защищено» владелец должен включить **Enforce HTTPS** в Settings → Pages: переход в JavaScript не заменяет серверное принуждение HTTPS и действующий сертификат.


## Отправка обращений

Форма в `index.html` отправляет данные по HTTPS через FormSubmit на `phystechonline3@gmail.com`. Поле `email` используется для ответа отправителю. Почтовые пароли и API-ключи в коде не нужны. Проверка отправки на стороне сервиса оставлена включённой.

Для первого запуска отправьте тестовое обращение с опубликованного сайта. Если FormSubmit пришлёт письмо активации на адрес школы, подтвердите его, затем повторите тест и проверьте входящие и папку «Спам». Подтверждение может выполнить только владелец почты.

После принятия формы сервис возвращает посетителя на `contact-success.html`. Страница подтверждает принятие сообщения сервисом, но не проверяет доставку в почтовый ящик. При возврате назад поля формы сохраняются, а кнопка отправки снова становится доступной.

Проверку интерфейса и содержимого POST-запроса можно выполнять с перехватом запросов к FormSubmit. Это не заменяет проверку доставки настоящего письма. В облачной среде запросы к `formsubmit.co` заблокированы текущей сетевой политикой; внешний сервис и почтовая активация должны быть проверены из браузера владельца сайта.
